    Guide

    Getting the look onto the camera

    1 · Set it on the go

    Under two minutes with the camera in hand. Values below come from the current recipe and skip anything you already have set.

    2 · Save it as a custom colour profile

    The X-T50 has seven custom settings banks, C1 to C7. Each stores the whole IQ recipe so you can switch looks in one move.

    1. Dial in the recipe first, using the steps on the left.
      A bank is a snapshot of what the camera is set to right now, so get everything right before saving.
    2. MENU/OK › IQ › EDIT/SAVE CUSTOM SETTING › CREATE NEW › pick an empty bank (C1–C7) › MENU/OK.
      Choose SAVE when it asks. The bank now holds film simulation, WB and shift, DR, tone, colour, sharpness, NR, clarity, grain and colour chrome.
    3. Name it: same menu › the bank › EDIT CUSTOM NAME. Try .
      Short names are easier to read in the Q menu tile.
    4. Set AUTO UPDATE CUSTOM SETTING to DISABLE.
      IQ › EDIT/SAVE CUSTOM SETTING › the bank › AUTO UPDATE CUSTOM SETTING. With ENABLE, every tweak you make while shooting is written back into the bank and your saved look drifts. With DISABLE, experiments stay temporary and the bank keeps the recipe.
    5. Recall it: MENU/OK › IQ › SELECT CUSTOM SETTING › C1–C7.
      Faster: put SELECT CUSTOM SETTING on a Fn button (SET UP › BUTTON/DIAL SETTING › FUNCTION (Fn) SETTING) or as the first Q menu tile (EDIT/SAVE QUICK MENU). Then one press and a turn of the rear dial swaps the whole look.
    6. Mind the Film Simulation dial: it overrides the bank.
      If the dial points at Classic Chrome, you get Classic Chrome even when the bank says Nostalgic Neg. Set the dial to C so the camera uses the bank's own film simulation, or turn it to the matching position.
    7. Check a frame in this app.
      Drop a JPEG shot with the bank active and compare it to the recipe. The camera writes every setting into the file.
    Film Simulation dial cheat sheet

    Eight simulations have fixed positions. The rest go into the FS1, FS2 and FS3 slots (IQ › FILM SIMULATION DIAL SETTING) or are chosen from the menu with the dial on C. C is the plain, unboxed letter on the dial between STD and FS3, easy to miss next to the icons. It means "let the menu decide", so the camera uses whatever IQ › FILM SIMULATION or the active custom bank says.
